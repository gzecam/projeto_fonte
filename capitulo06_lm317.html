CAPÍTULO 6

Regulador Ajustável LM317

1. Introdução

O LM317 é um regulador linear ajustável de três terminais amplamente utilizado em projetos eletrônicos.

Possui proteções internas contra:

  • Curto-circuito;
  • Excesso de temperatura;
  • Sobrecorrente;

Além disso, permite ajustar a tensão de saída através de apenas dois resistores.

2. Características Principais

Parâmetro Valor
Tensão de Saída 1,25V a 37V
Corrente Máxima 1,5A
Proteção Térmica Sim
Proteção Contra Curto Sim

3. Pinagem

LM317 ___________ | | IN ---| 1 3 |--- OUT | | ADJ --| 2 | |___________|

4. Funcionamento Básico

Internamente o LM317 mantém uma tensão de referência fixa entre os terminais OUT e ADJ.

Vref = 1,25V

A partir dessa referência é possível determinar a tensão de saída através de uma rede resistiva.

5. Circuito Básico

LM317 41V ─── IN OUT ──────► Vout │ R1 │ ADJ │ R2 │ GND

6. Equação do LM317

Vout = 1,25 (1 + R2/R1)

Esta será a principal equação utilizada no projeto.

7. Escolha de R1

Os fabricantes recomendam o seguinte valor padrão:

R1 = 240Ω

Esse valor será utilizado em nosso projeto.

8. Determinação de R2 para 33V

33 = 1,25 (1 + R2/240)
26,4 = 1 + R2/240
25,4 = R2/240
R2 = 6096Ω
R2 ≈ 6,1kΩ

9. Solução Prática

Para permitir ajuste contínuo utilizaremos:

R1 = 240Ω

R2 = 1kΩ + Potenciômetro 5kΩ

Isso permitirá variar a saída desde aproximadamente 1,25V até valores próximos de 33V.

10. Verificação da Tensão Máxima

R2 = 1000 + 5000
R2 = 6000Ω
Aplicando:
Vout = 1,25 (1 + 6000/240)
Vout = 1,25 (26)
Vout ≈ 32,5V

Valor extremamente próximo da especificação nominal.

11. Capacitores de Estabilidade

Os capacitores evitam oscilações e melhoram a resposta dinâmica do regulador.

Entrada 100nF
Saída 100nF
Saída 10µF

12. Corrente Máxima da Saída

A especificação do projeto é:

Imax = 1A

O LM317 suporta até aproximadamente 1,5A, atendendo ao requisito.

13. Eficiência Teórica

Considerando:

Vin = 41V
Vout = 33V
η = Vout / Vin
η = 33 / 41
η = 0,805
η ≈ 80,5%
