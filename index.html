Apresentação

Esta apostila tem como objetivo desenvolver o projeto completo de uma fonte linear de alimentação de forma prática e aplicada à Engenharia Elétrica.

Durante o desenvolvimento serão estudados os conceitos de proteção elétrica, transformadores, retificação, filtragem capacitiva e regulação de tensão utilizando duas tecnologias distintas:

  • Regulação através de diodo Zener
  • Regulação através do circuito integrado LM317

Ao final da apostila o estudante será capaz de dimensionar seus próprios circuitos de alimentação linear para aplicações de baixa potência.

Objetivos de Aprendizagem

  • Compreender a estrutura completa de uma fonte linear.
  • Dimensionar transformadores para aplicações eletrônicas.
  • Projetar sistemas de proteção com fusível e NTC.
  • Calcular pontes retificadoras.
  • Calcular capacitores de filtro.
  • Analisar o fenômeno do ripple.
  • Projetar reguladores utilizando diodos zener.
  • Projetar reguladores baseados no LM317.
  • Realizar análises térmicas.
  • Interpretar esquemas elétricos de fontes lineares.

Competências Desenvolvidas

Ao concluir esta apostila o aluno será capaz de:

  • Projetar fontes lineares completas.
  • Dimensionar componentes através de cálculos analíticos.
  • Interpretar folhas de dados (datasheets).
  • Avaliar dissipação de potência.
  • Realizar medições em laboratório.
  • Comparar diferentes técnicas de regulação.
  • Validar projetos eletrônicos através de critérios de engenharia.
