CAPÍTULO 5

Regulador de Tensão por Diodo Zener

1. Introdução

Após a retificação e filtragem obtivemos uma tensão aproximada de:

Ventrada ≈ 41Vcc

Esta tensão varia com:

  • Flutuações da rede elétrica;
  • Ripple residual;
  • Corrente consumida pela carga.

Precisamos então criar uma tensão estável e regulada.

2. O Diodo Zener

O diodo zener é um dispositivo semicondutor projetado para operar na região de ruptura reversa.

Quando polarizado reversamente e atingida sua tensão de ruptura, ele mantém a tensão praticamente constante em seus terminais.

3. Curva Característica do Zener

Corrente ↑ │ │ │ / │ / │ / ---┼-------------/--------------► Tensão │ │ │ │ │ └─────────────┐ │ │ Região │ Zener

Após atingir a tensão zener, grandes variações de corrente provocam pequenas variações de tensão.

4. Especificação da Saída

Parâmetro Valor
Tensão de Saída 33Vcc
Corrente Máxima 100mA
Regulador Diodo Zener

5. Circuito Regulador

+41V │ Rs │ ├───────────────► +33V │ ┌─|<|─┐ │Zener│ └─────┘ │ GND

O resistor limita a corrente enquanto o zener estabiliza a tensão.

6. Escolha do Diodo Zener

Desejamos uma saída de 33V.

Vz = 33V

Além disso, precisamos suportar aproximadamente 4W durante condições críticas.

Componente sugerido:

1N5367B
Vz = 33V
Potência = 5W

7. Corrente do Projeto

A saída deverá fornecer:

Icarga = 100mA

Além disso, o zener deve conduzir uma corrente mínima para manter a regulação.

Iz = 20mA

Assim:

Itotal = Icarga + Iz
Itotal = 100mA + 20mA
Itotal = 120mA

8. Cálculo do Resistor Série

Aplicando a Lei de Ohm:

Rs = (Vin − Vz) / I
Rs = (41 − 33) / 0,12
Rs = 8 / 0,12
Rs = 66,7Ω

Escolha comercial:

Rs = 68Ω

9. Potência Dissipada no Resistor

P = V × I
P = 8 × 0,12
P = 0,96W

Aplicando margem de segurança:

Resistor 68Ω / 2W

10. Potência Máxima no Zener

A pior condição ocorre quando não existe carga conectada.

Toda corrente passa pelo zener.

Iz = 120mA
Pz = Vz × Iz
Pz = 33 × 0,12
Pz = 3,96W

Portanto:

Zener mínimo = 5W

11. Eficiência do Regulador Zener

Potência útil:

Putil = 33 × 0,1
Putil = 3,3W

Potência consumida:

Pentrada = 41 × 0,12
Pentrada = 4,92W

Eficiência aproximada:

η = (3,3 / 4,92) × 100
η ≈ 67%
